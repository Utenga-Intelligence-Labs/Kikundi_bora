# Money Seeking

Mfumo wa kidijitali wa kusimamia vikundi vya Money Seeking na mikopo — kwa Kiswahili, kwenye simu na desktop.

## Vipengele

- **Wanachama** — Sajili na hariri taarifa za wanachama wote wa kikundi
- **Michango** — Rekodi na fuatilia michango ya kila mwezi kwa kila mwanachama
- **Mikopo** — Toa mikopo, fuatilia salio na muda wa kurejesha
- **Marejesho** — Rekodi marejesho ya mikopo kwa urahisi
- **Ripoti** — Ripoti za uwazi za hali ya kikundi kwa ajili ya vikao
- **Mifumo ya Majukumu** — Dashibodi tofauti kwa Mwenyekiti, Mweka Hazina, Katibu na Mwanachama
- **PWA** — Inafanya kazi kama Progressive Web App, inaweza kusakinishwa kwenye simu

## Teknolojia

| Kategoria | Teknolojia |
|-----------|-----------|
| Framework | React 19 + TypeScript |
| SSR / Routing | TanStack Start + TanStack Router (file-based) |
| Data Fetching | TanStack React Query |
| Styling | Tailwind CSS v4 |
| UI Components | shadcn/ui (Radix UI) |
| Build Tool | Vite 8 |
| Forms | React Hook Form + Zod |
| Charts | Recharts |
| Icons | Lucide React |
| PWA | vite-plugin-pwa |

## Kuanza

### Mahitaji

- Node.js 18+
- npm, bun, au package manager yoyote

### Usakinishaji

```bash
# Clone repo
git clone <repo-url>
cd Frontend-1

# Install dependencies
npm install

# Start development server
npm run dev
```

- **Mwenyekiti** — Anaona muhtasari wa jumla, anaidhinisha mikopo, anaona ripoti
